# Release Readiness Review

Prepare a release-readiness review for the current branch.

## Check

- Affected surfaces: site, schema, Move package, docs, GitHub automation.
- Required commands and whether they passed.
- Schema or Move API compatibility risks.
- Wallet, Sui transaction, Walrus upload, MVR verification, or governance risks.
- Manual steps that must not be automated.

## Output

- Release summary.
- Required checks.
- Manual checklist.
- Known risks.
- Recommended go/no-go.
